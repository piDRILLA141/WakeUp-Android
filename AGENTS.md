# Правила проекта «Подъём»

- Надёжный звонок важнее количества функций. Основные функции бесплатны, работают офлайн и доступны на русском языке. Реклама, подписки, регистрация и серверы требуют отдельной задачи.
- Сохраняй Kotlin, Compose, Material 3, Room, DataStore и AlarmEngine. Используй официальные Android API. Точные будильники планирует AlarmManager. Сохраняй applicationId, данные и совместимость, включая миграции без удаления данных.
- Сохраняй исправные компоненты. Минимизируй зависимости, фоновые службы и расход ресурсов. Секреты и личные данные остаются в защищённых хранилищах.
- Самостоятельно выполняй обратимые изменения и исправляй ошибки. Публикация, удаление данных, изменение секретов или концепции продукта требуют согласования.
- Начинай с чтения кода. Затем реализуй изменение, добавь тесты регрессий, исправь ошибки, повтори проверки, собери APK, сохрани работоспособные Git-коммиты и отчитайся по фактам.
- Сохраняй важные тесты и различай компиляцию, JVM, эмулятор и физическое устройство. При недоступности Cloud используй GitHub Actions. Ручные установки промежуточных версий не обязательны.
- Экономь контекст и вычисления. Дорожную карту и проверки устройств веди в документации.
