# Скачивание проекта и документации

Workflow «Android» создаёт четыре отдельных ZIP-артефакта на странице каждого запуска
GitHub Actions. Войдите в GitHub, откройте успешный запуск и найдите раздел Artifacts.

| Артефакт | Содержимое |
|---|---|
| `podyom-debug-apk` | Установочный `podyom-debug.apk` и SHA256SUMS |
| `podyom-source` | Архив podyom-source.zip: все исходники выбранного коммита, Gradle Wrapper, ресурсы, тесты и документация |
| `podyom-guide` | README со структурой проекта, установкой и настройкой OriginOS; архитектура и сценарии проверки телефона |
| `podyom-check-results` | RESULTS.md, фактический журнал сборки, HTML/ XML JUnit и Android Lint текущего запуска |

Артефакты хранятся 30 дней. GitHub сам упаковывает каждый из них в скачиваемый ZIP.
Исходники выгружаются через `git archive`: локальные кеши, SDK, APK, ключи и
незакоммиченные файлы в этот архив не попадают. Документация и исходники относятся
к коммиту соответствующего запуска. В отчёте RESULTS.md указаны коммит и дата.

После скачивания исходников распакуйте архив GitHub, затем вложенный podyom-source.zip
(он сохраняет права запуска Gradle Wrapper), и откройте папку с settings.gradle.kts
в Android Studio. Для просмотра документации откройте README.md. Отчёты HTML нужно
открывать после распаковки всего архива, чтобы сохранились относительные ссылки.

VALIDATION.md в документации описывает первоначальную проверку проекта. Актуальные
числа тестов и предупреждений конкретного запуска находятся в RESULTS.md и сырых
отчётах артефакта `podyom-check-results`.
