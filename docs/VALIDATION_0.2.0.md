# Проверка 0.2.0

Локально выполнен полный набор Gradle: core:test, app:testDebugUnitTest,
app:assembleDebug, app:assembleDebugAndroidTest, app:lintDebug. Успешно.
58 тестов, 0 неудачных. Из них 33 чистых Kotlin/JUnit и 25 Android/Robolectric/
Compose на API 36. Lint: 0 ошибок; предупреждения сохранены в исходном отчёте.

Дополнительно проверены подпись v2 APK, метаданные applicationId/versionCode,
ZIP-выравнивание 16 КБ, сохранение публичного сертификата первоначальной локальной
0.1.0 и отсутствие APK/keystore в Git. Таблицы Room и экспортированные схемы не
менялись, разрушительных миграций нет. Прочитаны legacy JSON будильников/настроек,
проверено восстановление расписания и переходы существующей state machine.

Новые проверки: 640→06:40 и остальные варианты, недопустимый ввод, отображение
двоеточия и отображения курсора, удаление/замена текста, копирование +10 с переносом
дней недели и сохранением ближайшей абсолютной даты, активная системная регистрация,
быстрый +20 и защита повторного нажатия, восстановление и отсутствие повторения,
обычное выключение без миссий, заметный диалог внутри приложения, повторное уведомление
в новом цикле, своевременное/просроченное подтверждение, двойное подтверждение,
сохранение пользовательского запрета старого канала, опциональное наложение и очистка.

Снимки обеих тем и нового диалога получены настоящей отрисовкой Compose под
Robolectric; это не снимки физического телефона.

В GitHub Actions все проверки запускаются ещё раз. Актуальный отчёт этого запуска —
RESULTS.md в артефакте podyom-check-results; сравнение сертификата с прежним GitHub
APK — signing/SIGNING.md. Эта локальная проверка не подменяет результаты CI.
