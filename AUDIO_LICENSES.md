# Источники звуков

Встроенные звуки — оригинальные синтезированные последовательности проекта «Подъём».
Авторство указано по исходнику `scripts/generate_sound.py` и истории Git проекта.
Сторонние записи, композиции и звуковые сервисы не использовались. Отдельная лицензия
от стороннего автора и атрибуция не требуются. Отдельная лицензия на аудио в проекте
пока не объявлена.

| ID | Название | Источник и обработка |
| --- | --- | --- |
| `dawn` | Рассвет | Исходная последовательность проекта, моно PCM 22,05 кГц |
| `bell` | Утренний звон | Новый синтез, моно PCM 16 кГц |
| `pulse` | Пульс | Новый синтез, моно PCM 16 кГц |
| `signal` | Сигнал | Новый синтез, моно PCM 16 кГц |

Три новых сигнала вместе занимают около 184 КиБ. Для гладкого зацикливания
огибающая подводит каждую ноту к нулю на границах. Пик новых сигналов ограничен
22 000 отсчётами из 32 767. Они начинаются с короткой атаки, без тихой паузы.
Мелодии из файлов пользователя и из системной коллекции не входят в дистрибутив.
